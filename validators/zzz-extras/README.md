# Extra validators

Questa cartella raccoglie controlli non specifici per l’Italia.

Sono regole di interesse potenzialmente generale, mantenute qui finché non trovano una collocazione più adatta nel validatore di JOSM o in un’altra raccolta condivisa. La loro presenza in `zzz-extras` le distingue dai controlli italiani senza nasconderne il possibile valore per il resto della comunità.
